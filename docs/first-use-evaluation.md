# 初見評価：説明なしで最初の1件を追加できるか

2026-09-12の改善後に実施する。まだ初見利用者による再評価は行っていない。開発者のブラウザ操作・自動テストと区別する。

## 準備

- 操作方法やこの記録用紙を先に見せない。本人の実データを使わず、架空の課題「SQL exercises」を使う。
- 第1回はログイン済みの空一覧を開いておく。これで今回変更した1〜4を評価する。
- 別の初見利用者、または別セッションではサインイン前から測り、アカウント作成を含む負担を別に記録する。ログイン後の改善を、認証込みの1操作達成と混同しない。
- 検証用アカウントを使う。既存の本人データを消して空にしない。

## 伝えること

「今週取り組む課題がSQL exercisesだとして、このアプリで管理してみてください。」

その後は横から説明・誘導をしない。操作に関する質問にもその場では答えず、質問内容と時刻を記録し、終了後に回答する。本人が中止したい場合は中止する。

## 追加の確認（最初の登録が終わってから）

1. 見本の学期を自分で開いて戻れるか。
2. 最初のカードに科目と日付を追加できるか。
3. 観察者が見本内の1件を今日締切に設定してから、期限超過・今日締切のカードを含む見本を見せ、今取り組む課題を言ってもらう。見てから回答までを測る。
4. 「この画面は学校へファイルを提出しますか」と終了後に尋ね、注意書きの理解を確認する。
