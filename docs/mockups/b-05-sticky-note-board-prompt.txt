Use case: ui-mockup. Generate ONE polished landscape 3:2 design comparison board with THREE large mobile web app screen panels, readable text, for a TAFE/VET student assessment tracker.
This is an alternative concept to a rounded-card form: a tactile STICKY-NOTE SEMESTER BOARD, like arranging notes on a personal notebook page. Keep it mature, extremely simple, practical, and warm. Cream ivory background, dark teal typography/buttons, pastel butter-yellow, peach, lavender paper notes, very light notebook ruling and restrained paper folds. Slight playful note tilt only for visual warmth, crisp functional UI text. No photos, no actual phone hardware, no 3D perspective. Serif major headings and clear sans-serif controls. Plenty of breathing space. No XP, points, levels, mascots, grades, streaks, confetti or AI/chatbot.

Above the screens, title "A little space for each task"; small subtitle "Concept B · The sticky-note board". Three short outside panel labels "01  Write one thing", "02  It has a place", "03  See your week". Narrow arrows between the panels. All image text English, correctly spelled, generous readable type.

SCREEN 1, first visit AFTER sign-in: small header wordmark "Assessments." and a gear icon. Heading "My board". Sentence "What is on your plate?" The center is a pale-yellow sticky note with a folded lower corner and the single text input label "Assessment name", input placeholder "e.g. SQL exercises", a round dark-teal button labelled "Add" directly to the right of input. Beneath input small line "Dates and units can wait." No save button, no unit requirement, no empty table or multiple choices. Under sticky note link "See an example". Bottom slim navigation "Board" active and "Submitted". This initial state only asks for the title.

SCREEN 2, immediately after addition: same header and "My board". A tidy notebook-like surface with ONE area labelled "No date yet", a subtle rounded underline. One yellow sticky note with title "SQL exercises", small optional chip "+ Unit", and direct chip "+ Date", plus tiny pencil icon. A short unobtrusive callout "Your first task has a place." Below this note show a small date action popup anchored to the tapped "+ Date" chip, with three clearly labelled options "Today", "Tomorrow", "Choose a date". This is optional, not a mandatory step. Put a minimal pointer/cursor on "Today". Do not show a calendar grid in this concept board, "Choose a date" will open the existing date calendar with typed-date readback. Permanent slim input bar above bottom navigation "Add another assessment…" with plus button. Bottom navigation same.

SCREEN 3, a later example AFTER A FEW ADDITIONS, not the same single-item dataset: same header, heading "My board", small date "Friday 16 October". Three VERTICAL, easy-to-scan bands: "Today" at top with strong teal label, "Coming up" second, "No date yet" last. These are date-derived sections, NOT completion workflow stages. Today contains a large yellow sticky note "SQL exercises", small unit label "Database", high contrast small "Due today" indicator, obvious dark teal button "Mark submitted". Coming up contains a smaller lavender note "Website review", "Web Development", small date "19 Oct". No date yet contains a smaller peach note "Project proposal" and small "+ Date" chip. Keep all three visible without crowding. Notes look attachable and tactile, but all controls are normal tap targets; no drag handles or drag instructions. Permanent compact bottom input bar "Add another assessment…" plus button and Board/Submitted tabs. Tiny outside-panel caption clarifies "Example after adding a few tasks".
No visible trash, backup, sync or revision vocabulary on normal screens. Gear keeps advanced settings reachable. No cloud setup, login forms, prices or mock analytics. Do not imply Mark submitted uploads files to a school. Lower board footer outside screens in small text: "Write a note. Give it a date. Find it where you expect."
The visual contrast versus the previous concept is a personal notebook with flat sticky notes and simple time-based spaces, rather than floating rounded database cards. Aim for immediate understandable actions, a satisfying sense of placing tasks, and relaxed student stationery aesthetic.
